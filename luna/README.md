# Luna — TheYKHC事業統合・新事業生成エンジン

Lunaは、リポジトリに保存されたDOI台帳、問い、事業候補、カタログを統合し、出典を保持したまま新事業の**検証候補**を生成します。

## 重要な境界

- DOI登録は査読、科学的実証、資産価値を意味しません。
- 過去のGO判定や市場規模を事実として継承しません。
- 医療・金融・安全重要領域は既定で生成対象から除外します。
- 出力は事業の成功宣言ではなく、顧客検証を始めるための仮説です。

## 起動

```bash
python3 -m luna.cli --inventory
python3 -m luna.cli --generate 10 --output luna_snapshot.json
```

高危険度候補を監査目的で確認する場合だけ、明示的に指定します。

```bash
python3 -m luna.cli --generate 10 --allow-high-risk
```

## 出力内容

- 読み込めたデータセットと件数
- 5層分類に対応する構造分類
- 医療・金融・安全・未成年者の危険フラグ
- 根拠状態
- 新事業候補の出典レコード
- 最初の顧客検証、指標、中止条件、安全ゲート

`status: operational_local` は、このリポジトリのスナップショットに対してローカル実行できるという意味です。Base44、Zenodo、Webサイトとの常時同期を意味しません。
