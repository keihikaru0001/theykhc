# Closed-System Integrity — 光貨圏ガラスの器

## 絶対則
光貨（Hikari）は光貨圏内でのみ流通する共鳴マーカーである。以下を恒久的に禁止する：

1. **外部流出禁止**: Hikariトークンを外部システムに送金・換金・譲渡することは不可
2. **外部流入禁止**: 実社会の法定通貨がゲーム内価値（V）計算に流入することは不可
3. **内部起源のみ**: 全てのHikari取引の起源は内部（ゲーム報酬、取利益、初期割当）でなければならない
4. **違反検知**: 外部受取人または外部資金源を参照する取引を検出した場合、即座に拒否し、閉鎖系違反としてGameEvent（type: investigation）を記録し、会長・片山佳光へ報告する

## 閉鎖系の定義
- 光貨圏は「ガラスの器」——外部から観測は可能だが干渉は不可
- 光貨購入代金は外部収益であり、圏内価値計算には一切流入しない
- リアルマネーは光貨圏の壁を越えない。永久に交わらない

## 会長の言葉
「光貨は金融商品ではなく、光貨圏内のみで流通する共鳴マーカーであり、外部への換金・決済・譲渡は一切不可能である。」
