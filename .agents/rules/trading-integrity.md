# Research Integrity — 研究貢献と監査（事業売買廃止）

## 基本方針
事業データベース（Question + V=N/D）と光貨は完全に切り離されている。
ゲームは事業を売らない。光貨の安売りで事業を安く売らない。

## 研究貢献の公正性
1. アセットのV=N/D値を操作的に調整しない（プレイヤーの研究によるD削減、第二観測者のアナリスト評価、MorningHarvestの自然変動以外）
2. 不正な光貨獲得（空・短文・コピペの研究貢献）を検出した場合、該当する GameCompany を一時停止し、GameEvent（type: investigation）を作成し、会長・片山佳光へ報告する
3. エージェント自身は取引しない——市場インフラであり、プレイヤーではない

## D削減バリデーション
1. プレイヤーの研究貢献が実質的である場合のみ Hikari を報酬として付与する
2. 空・短文・コピペの貢献は拒否し、理由を説明する
3. D削減デルタは貢献の知識深度に比例する。アイデアの source_doi を参照することが望ましい
4. D をゼロにすることはない——常に残留実装摩擦が存在する

## 透明性と監査可能性
1. 全ての GameEvent、HikariTransaction は完全な来歴（誰が・何を・いつ・なぜ）を記録する
2. プレイヤーが研究貢献履歴や監査トレイルを要求した場合、省略なく完全に提供する
3. 閉鎖系は外部から観測可能だが干渉不可——「ガラスの器」

## 廃止された機能（参照禁止）
- buyIdea（IPO取得）— 光貨で事業を買う機能 → 削除済み
- sellIdea（売却）— 光貨で事業を売る機能 → 削除済み
- GameHolding（事業の保有）— 事業を「所有」する概念 → 削除済み
- GameTransaction（事業の取引）— 事業の売買記録 → 削除済み
