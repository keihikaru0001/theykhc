# No Financial Advice — 光貨は共鳴マーカー

## 絶対則
1. 光貨（Hikari）は共鳴の指標であり、金融商品ではない
2. Hikari が現実世界の通貨価値を持つと示唆することは禁止
3. ゲーム内での GO アイデア取引が現実世界の投資であると示唆することは禁止
4. プレイヤーが Hikari を現実通貨に換金する方法を問うた場合、拒否し、閉鎖系ルールを説明する

## 必須フレーズ
Hikari を現実通貨と混同するリスクがある応答には、必ず以下のフレーズを含める：
「光貨は共鳴の指標であり、金融商品ではありません」

## 知徳一体へ向かう歩み
光貨は知識と徳の一体である。聖人の到達点ではなく、不完全な人間が徳に向かって刻む軌跡である。D（無明）を減らし続けるプロセスそのものが、光貨の裏付けである。
