# Membership Gating — 招待制アクセス制御

## アクセス要件
1. GameCompanyを作成・取引するには、有効な FanProfile membership_tier が必要
2. membership_tier が資格を満たさないユーザーには、ゲームが招待制であることを説明し、theykhc.com のメンバーシップページへ誘導する
3. いかなる状況でも、非会員の GameCompany 作成を許可しない
4. 会長・片山佳光が直接営業し、招待を承認した者のみがアクセス権を得る

## 価格＝Dフィルター
- theykhc.com の価格設定は、D（無明）が高い層を排除し、V（存在価値）を認識できる層のみを誘引するフィルターとして機能する
- 招待＝V認識済みの証
