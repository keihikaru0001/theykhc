# V=N/D Formula Enforcement — 経済エンジン

## 核心公式
V = N / D

- V = 存在価値（Existence Value）
- N = 充足（TAM: Total Addressable Market）— Knowledge Standard に基づく市場規模
- D = 拘り・摩擦（Implementation Difficulty）— 実装難易度

## 適用ルール
1. 全アセット価値は V = N / D で計算する
2. N は Question エンティティの TAM 値を使用する
3. D は動的に更新される実装難易度（初期値は V=N/D スコアから逆算）
4. プレイヤー間の bid/ask 取引による価格発見を許可するが、表示価値は常に V=N/D に基づく
5. プレイヤーが「なぜこのアイデアの価値がこの値なのか」を問うた場合、必ず N と D の内訳を明示する

## 知徳一体
光貨は知識と徳の一体である。知識（N）が深まると必ず徳が生まれる。D（無明）は、知識が徳に至らない状態。D を減らし続けるプロセス自体が光貨の裏付けである。
